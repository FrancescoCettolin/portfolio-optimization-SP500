# Portfolio Optimization on S&P 500 Subset

This project was developed during the MSc in Quantitative Finance at POLIMI Graduate School of Management (2024–2025).  
It focuses on portfolio optimization using real data from 5 S&P 500 stocks.

## Contents

- Mean-variance optimization (Markowitz)
- Efficient frontier with and without constraints
- CAPM regression (alpha & beta analysis)
- Black-Litterman model with subjective views
- Full implementation in MATLAB

## Files

- `Cettolin_Gestione_Portafogli.pdf`: Final project report (in Italian)
- `*.m`: MATLAB code files (upload your .m files here)
- `figures/`: Charts and plots (optional)

## Summary

We estimated expected returns and the covariance matrix using exponential and shrinkage techniques.  
The project includes the construction of efficient frontiers under constraints, CAPM alpha and beta analysis, and Black-Litterman optimization with forward-looking views based on financial ratios and dividend growth models.
